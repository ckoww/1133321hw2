# 1133321hw2 記憶翻牌遊戲
這是翻牌記憶配對遊戲，玩家需要透過翻牌找出相同圖片的配對，當所有卡片成功配對後，表示完成遊戲。
<img width="698" height="1075" alt="image" src="https://github.com/user-attachments/assets/8115114a-fd18-43b1-a4e8-35e9e6169b8d" />
總共有8張花色為黑桃的撲克牌:分別是1、2、3、4、10、J、Q、K
1. 開始遊戲
執行程式後，系統會：
•	自動洗牌 
•	將所有卡片蓋上背面 
•	開始計時 
玩家即可開始翻牌。
2. 翻牌規則
玩家每次可點選兩張卡片：
配對成功 若兩張圖片相同
•	卡片會保持正面 
•	視為成功配對
配對失敗 若兩張圖片不同
•	系統會短暫顯示圖片 (影響過關秒數的懲罰翻錯機制)
•	接著自動翻回背面
3. 偷看功能（提示）遊戲提供一次「偷看」功能，並且新增語音音效嘲諷。
按下提示按鈕後：
•	所有卡片會暫時顯示正面，幾秒後自動蓋回 
•	每場遊戲只能使用一次(按鈕之後會無法使用)
<img width="686" height="1066" alt="image" src="https://github.com/user-attachments/assets/2434ff9a-6454-479f-a050-ec9b91171d62" />

 
5. 過關畫面
當所有卡片成功配對後：
•	遊戲停止計時 
•	播放過關音效 
•	顯示完成時間
 
按下右上GAME選單中的Restart即可重新開始新的一局。
